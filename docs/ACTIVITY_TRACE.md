# 思考摘要与工具轨迹

[返回 README](../README.md) · [H5 API](WEB_UI.md) · [模块组合](ARCHITECTURE.md)

每条新回复有两个可折叠区域：**思考摘要**与**工具轨迹**。上方显示当前阶段、模型调用轮数、工具调用次数和实际已用时间。支持浅色/深色、窄屏、键盘操作和导出本轮 JSON。

## 摘要是什么

这里的“思考摘要”是 **程序按真实执行事件整理的概览**，不是模型内部思维链，也不是模型生成的计划。它记录已使用的模型、带入的历史轮数/附件数、实际模型调用、格式修正、工具动作及终态。不预测下一步，不调用云端或额外的摘要模型，不把按时间增长的文案伪装为推理。

模型返回 `model_output` 时，只向页面发送字符数量和是否包含前置 `<think>` 段；原始推理不进入公开轨迹。对话答案会分离前置的完整 `<think>…</think>`，只有正文进入会话和下一轮历史。未闭合或没有正文时明确失败。代码示例或正文中间的同名标签不剥除。原始回复保留在本机 Audit JSONL，可能有敏感信息，不应公开上传。

这不启用或强制模型“思考模式”，不改变模型提示模板、动作协议或 `/no_think` 策略。没有推理内容的模型也能展示执行概览；当前仍为完整轮次输出与事件长轮询，不是逐 token streaming。

## 工具轨迹

每次调用使用独立 ID，即使连续调用同一工具，也不会互相覆盖。状态区分：准备调用、等待确认、执行中、已完成、失败、已拒绝、确认超时、已停止、已中断。

**提出调用不代表工具已执行。** `tool_start` 是请求；`approval_required` 是等待；实际进入 Registry 前发出 `tool_execute`；`tool_result` 才确定成功/失败。独立生图与 Agent 共用这条记录链，普通对话不会伪造工具步骤。权限和审批保持原样，不新增 HTTP 授权开关。

分别记录“等待确认”“工具执行”“调用总计”三个耗时，使用单调时钟；等待确认时间不计为工具执行时间。取消请求先显示“正在停止”，直至当前任务实际结束；已完成的副作用不会被撤销。最终回答成功也不会把此前失败或拒绝的工具改成成功。

输入与结果是有界的显示副本：最多 120 个最近步骤，长文本/深层结构截断，常见密钥字段、Bearer 字符串和部分 URL 凭证遮蔽。**这不是完整的数据防泄漏系统**，自由文本中的私人数据仍可能显示。原始审计、旧版 trace 和审批参数保持原有用途，不受显示副本替代；导出前请检查业务资料。HTML 一律作为文本显示，不执行脚本或载入远程图。

## 记录与恢复

`Run.activity` 在原有事件进入时同步更新。`GET /api/runs/<id>/events?after=<cursor>` 除原有字段外返回 `activity` 快照，不改变事件游标意义；重读事件不会重复生成步骤。仍要求原有 token、Host/Origin 检查，不开放公开日志 API。

阶段变更原子保存到 `state/runs/<run_id>.activity.json`，最终快照同时进入会话 assistant 消息的 `activity` 字段。刷新会从服务器恢复进行中的任务与审批；服务重启时，未完成步骤标为中断，保留最近实际记录的耗时，不自动重放模型或工具。

旧会话没有 `activity` 字段时继续显示已有工具记录，不为历史伪造摘要。删除会话仍保留审计、checkpoint 与工作文件，当前没有自动清理保留期。新的 JS/CSS 通过固定同源资源路径提供，并由现有打包流程收集；安装版需覆盖安装相应新包才会更新网页组件。

## 实现入口

| 模块 | 职责 |
|---|---|
| `local_agent/activity.py` | 真实事件投影、时间/状态、显示限额与敏感键遮蔽、答案分离、恢复 |
| `local_agent/web.py` | Run / LiveAudit / 审批 / HTTP 和持久化的接入点 |
| `local_agent/webui/activity.js` / `activity.css` | 折叠摘要、工具明细、焦点/展开保持、导出与响应式样式 |
| `tests/test_activity.py` | 事件、实际 HTTP/文件、审批、取消、恢复与边界测试；模型明确为替身 |
| `scripts/browser_activity.py` | 真实 Chromium 与本地服务验收；模型输出为标注的测试样本 |

本地运行 `python -m unittest tests.test_activity -v`；完整测试 `python scripts/run_tests.py --output-dir reports/ci/activity`；浏览器测试 `python scripts/browser_activity.py --output reports/browser-activity`（需安装测试用 Playwright 与浏览器）。现有 `H5 browser acceptance` 已增加专项并保存截图。真实 Qwen HTTP 工作流仍单独执行，不能用替身用例的通过冒充实际模型验证。
