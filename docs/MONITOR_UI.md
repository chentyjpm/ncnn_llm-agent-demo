# 原生监控界面

管理窗口使用深蓝灰底色、统一的文本层级与青绿色选中态。资源卡片的曲线只使用真实样本，缺失值会断线；没有采样时不绘制虚假的历史数据。

旧版只修改了 `TNotebook.Tab` 的 padding，保留了主题自己的选中态/扩展几何以及旧表格边框，造成页签高低不齐、选中态不清晰。新版不再使用 Notebook 页签：等高导航按钮和独立内容容器分开布局，切换内容不改变导航位置。选中标记、悬停、焦点和禁用样式统一处理；左右键、Home/End、Ctrl+Tab 可切换。

窄窗口时资源卡片改为两列；小屏或较大缩放下整页可以滚动，不把底部操作截掉。表格按稳定 ID 更新，保留选择、焦点和滚动位置，数据更新不再删除并重建所有行。滚动条只在内容溢出时显示，过长的模型名只在展示层省略，原始诊断不修改。

`monitor_widgets.py` 管理颜色、字体密度、按钮、卡片和曲线；`monitor_ui.py` 只负责窗口组合和已有状态的展示，不修改 `monitor.py` / `gpu_stats.py` 采样、推理策略、审批权限或 Windows 静默启动规则。

`tests/test_monitor_presentation.py` 检查缺失值、单位、曲线断点、文本裁剪和对比度；`scripts/monitor_layout.py` 在真实 Tk 窗口上检查三组缩放、页签几何、鼠标与键盘切换、窗口缩小和选择保持，截图使用本次实际 OS 采样。100%/150%/200% 是 Tk 缩放模拟，不代替实体多屏之间移动窗口的逐显示器 DPI 验证。冻结程序的 `--monitor-test` 同样核对导航几何和切换。

采集范围、管理行为与平台限制见 [MONITOR.md](MONITOR.md)。
