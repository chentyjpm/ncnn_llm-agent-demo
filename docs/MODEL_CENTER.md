# 模型中心：来源、大小、安装阶段

## 用户操作

进入“安装与模型”，先选 `ModelScope 魔搭` 或 `Hugging Face`，再选择文本/生图模型。默认魔搭，选择保存在当前浏览器。页面不自动下载模型，也不会为获取魔搭模型而先请求 Hugging Face。

点击 **准备下载**，立即显示“正在连接所选来源，查询文件大小”；此时只请求文件清单，不下载权重。查询最长等待约 30 秒，失败会持续显示错误，按钮恢复可点击。查看下载源、所需下载字节、安装后的估算大小、安装时最低可用空间和当前磁盘空间后，再点击 **确认下载并安装**。改选来源会取消未完成的查询并使旧确认失效。下载开始后来源锁定，须取消本次安装后才能改选，不会偷偷切换。

“下载大小”是模型文件总字节数，不是下载次数，也不是当前已经下载了多少。界面以 GiB/MiB（1024 进制）显示；旧说明中的约 1 GB / 3.1 GB 是十进制近似值。所需空间包括转换时的临时文件预留，不是最低运行内存。

## 可选模型

| 模型 | HF 官方仓库 | 魔搭官方仓库 | 格式处理 |
|---|---|---|---|
| Qwen2.5 0.5B Instruct | Qwen/Qwen2.5-0.5B-Instruct | 同名独立仓库 | 下载 safetensors，自动转 ncnn |
| Qwen2.5 Coder 0.5B Instruct | Qwen/Qwen2.5-Coder-0.5B-Instruct | 同名独立仓库 | 下载 safetensors，自动转 ncnn |
| Qwen2.5 1.5B Instruct | Qwen/Qwen2.5-1.5B-Instruct | 同名独立仓库 | 下载 safetensors，自动转 ncnn |
| Qwen Image 2.1 | nihui-szyl/qwen-image-ncnn 内 qwenimage21 | 尚未核实到匹配 ncnn 镜像 | 使用原有 ncnn 生图格式 |

生图选择魔搭时明确显示不可用原因，不伪造镜像、不下载原始 PyTorch 权重替代，也不暗中改用 HF。用户须明确选择 HF 才能准备这一模型。应用仍默认 Vulkan 优先，预检无可用硬件才选 CPU；下载源和计算设备是两回事。

这里只开放三个经过结构适配的 dense Qwen2.5 文本模型，不能粘贴任意模型 URL。三个模型采用同类图结构，但隐藏维度、层数、注意力头和 RoPE 维度由各自严格的配置白名单决定。不是把目录换个名字就号称适配成功，也不是通用 GGUF/GPTQ 转换器。新增两种模型的实际推理范围看当前提交的 CI 结果，不从元数据或同架构推断已运行成功。

## 下载和准备状态

| 状态 | 用户看到的信息 | 进度含义 |
|---|---|---|
| 查询文件大小 | 来源、等待说明、查询超时/失败 | 未开始模型下载，不显示伪百分比 |
| 下载 | 当前文件、真实已收字节/总字节、速率、预计剩余、来源 | 真实网络/已验证缓存字节，不按时间假增长 |
| 校验 | 正在检查文件、已校验数量 | 校验失败停止；与下载阶段分离 |
| 转换 | 当前层/准备步骤 | 真实转换回调，不代表耗时百分比 |
| 最终校验/启用 | 已检查文件数 | 全部完成并发布 READY 才变为已启用 |
| 失败/取消/中断 | 原因、重试和来源说明 | 未完成模型不启用，不伪装成功 |

网络长时间无新数据时显示等待状态，不继续显示旧速度或编造剩余时间。下载 100% 只代表文件传输结束，校验、转换尚可能需要时间。无法测量的阶段使用不定进度条。

取消是合作取消：当前网络读取最多需要等待连接/读取超时，转换在下一个受控步骤检查取消。界面显示“正在取消”，直至工作线程实际退出；不是点击按钮就谎报已停止。

关闭安装对话框不会取消后台安装，再打开可恢复进度。页面刷新可重新获取状态。退出/重启整个应用会将遗留安装标为中断，不自动再次下载。任务状态保存在用户数据根目录 `model-job.json`，不包括账号令牌。

重试只复用 **同一来源、同一固定版本** 中已完整下载且通过校验的文件；未完成的单个 `.part` 文件重新下载。目前没有 HTTP Range 字节级断点续传，也没有并行分块下载。不要把文件级复用描述成完整断点续传。

## 来源与校验

`local_agent/model_catalog.py` 是模型及来源白名单。HF 和魔搭 Git 提交历史不同，分别固定 commit，不能把 HF 的 revision 直接用于魔搭。三个模型各自的权重 SHA-256 在两源实查一致，但同一模型的非权重元数据可能不同，因此仍按所选源清单逐文件验证。代码不要求配置 HF Token 或魔搭 SDK，不依赖两个源同时可达。

`local_agent/model_sources.py` 分别解析 HF 的 `siblings/lfs` 和魔搭的 `Data.Files`；拒绝未知来源、未知模型、非 HTTPS、跨源任意跳转、不安全路径、重复/缺失文件、无效大小/校验和。重定向只允许该来源的 CDN 域名范围。来源本身或公司代理不可达时需要用户检查网络或改选来源，应用不改系统代理、不安装驱动。

`local_agent/model_hub.py` 管理明确确认、真实下载进度、缓存、校验、转换和原子发布。READY 清单记录实际来源、版本和安装文件哈希；已有完整模型可以直接启用，不能在另一安装进行中切换。

## 验收与安装包

- `tests/test_model_center.py`：明确的元数据/网络替身，覆盖来源、哈希、阶段、取消和安全校验，不等于真模型运行。
- `scripts/browser_model_center.py`：真实 Chromium + 本地 HTTP，安装阶段由受控 fixture 驱动；验证可见来源、四张模型卡、查询/确认、字节进度、取消/刷新、错误和窄屏，不冒充真实下载。
- `scripts/catalog_source_probe.py`：真正访问两源、六个模型/来源组合；读取固定版本清单并下载/核对小型 config 文件，不下载大权重。
- `scripts/model_catalog_inference.py`：实际从魔搭安装 Coder 0.5B、从 HF 安装 1.5B，校验、转换并用真实 ncnn CPU 完成最小问答；原有 Qwen 0.5B 数值/工具/HTTP 验收保留。

GitHub Actions 分别保存真实日志和 JSON。发布结论必须根据该提交的实际 CI 状态，不能使用脚本存在或旧提交结果替代。Windows 已安装的旧程序不会因仓库推送自动改变，需安装本次成功构建的新安装包；程序升级不主动删除用户已有权重、聊天和工作文件。
