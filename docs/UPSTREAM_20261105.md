## Validation plan and boundaries

Keep the existing three compiler/OpenMP CPU jobs and their upstream Softplus
and Net tests. Add strict direct Softplus numerical checks and a Net negative
control in the GCC/OpenMP job: retain the new regression test, replace only
net.cpp with the old pin, require the exact unnecessary-clone failure, restore
the current source, rebuild and require test_net to pass. The negative control
must not accept an arbitrary compilation/runtime failure as proof.

Retain existing strict ARM FP16/BF16 and software Vulkan regressions, native
four-platform builds, real Qwen CPU inference and complete installers. Package
smokes are not model-inference evidence. Software Vulkan is not physical GPU
performance evidence. The narrow existing Intel Mac installer llm/image probe
exit=-6 exception does not waive new failures; no Release is created.

The cloud host has approximately 59 GiB disk and 9.1 GiB available RAM, with
GCC but no CMake, ARM toolchain or usable Vulkan SDK/device. Local Python tests
and independently compiled x86 tests cannot establish ARM, native integration,
model inference or packaging. Exact PR/main Actions evidence is required.

Local Python pre-publication result: 642 tests, 628 passed, 14 skipped, zero
failures/errors. Generated evidence: `reports/ncnn-36036f-tools/`. Skips are
11 missing optional Office-library checks and three Windows-only checks.

The direct Softplus companion compiles the actual upstream Mat/Option and
unchanged kernels, with CPU/OS ISA guards before execution. Its fixed FP32
budget is 1.2e-7 + 2e-6 times the absolute double-precision reference, plus
independently computed half-ULP BF16 storage rounding. NaN, infinities, overflow
neighbors, packing, dimensions 1–4 and SIMD tails have explicit checks.
The inherited log(1 + exp(x)) formula loses small negative-tail outputs to zero
through cancellation. This is measured and printed as an accuracy limitation;
the test does not claim full relative accuracy there or silently widen its
budget. The optional strict-negative mode rejects that limitation.

Local GCC direct execution passed scalar, SSE2, AVX, FMA, AVX2, AVX512 and
AVX512BF16 FP32/BF16 paths: 860,160 cases and 1,152,545,280 element checks.
FMA4 and AVXNECONVERT compiled but were not executed because CPU/OS support
was unavailable. Results and source hashes are recorded in
`reports/ncnn-36036f-softplus/`. Native dispatch, Clang and other operating
systems remain pending the corresponding CI gates at initial publication.
